Game-Friendly Equipment + Tile Pipeline Builder

Equipment should be simple upgradeable tools. Pipelines are not bought as one object: they are connected tile segments from a source to a destination.

Corrected Rule

Equipment Tree

Unlocks field capability: move, scan, build, drill, produce, connect.

Activity System

Player chooses a map action: survey, drill, build road, build pipeline route.

Not This

No abstract "buy pipeline" object. No table-only pipeline gameplay.

Pipeline Rule

Pick source tile, pick target tile, preview path, build connected segments.

Tile Rules For Pipelines
Valid Start Producing Well, Gathering Center, Processing Plant.
Valid End Gathering Center, Processing Plant, export edge.
Per-Tile Cost Flat desert $2M, dunes $3M, rocky tile $4M.
Connection Rule Every segment must touch the previous segment by tile edge.
Flow Rule Connected wells feed the nearest gathering center until capacity is full.
Upgrade Rule Pump Station Kit extends range and increases throughput.

How Actions Use Manpower

Survey Block

Needs: 1 Geoscience manpower.

Better with: Senior Geoscientist or Chief Geoscientist.

Build Road / Pad

Needs: Operations manpower + equipment.

Better with: Equipment Operator or Operations Superintendent.

Drill Well

Needs: Engineering manpower + Operations manpower + rig.

Better with: Senior Drilling Engineer and Rig Supervisor.

Operate Field

Needs: Facilities manpower + Operations manpower.

Better with: Facilities Engineer and Asset Manager.

Reduce Environmental Pressure

Needs: HSE manpower.

Better with: Environmental Specialist, HSE Lead, Sustainability Director.

Simple Gameplay Rule
Action available = required tech + required manpower type + cash/equipment + owned land

Example: Drill Well is not a manpower node. It is a map action that requires Exploration Wells tech, Engineering manpower, Operations manpower, a rig, cash, and an owned block.

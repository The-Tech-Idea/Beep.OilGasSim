Research-Backed Progression Model

Based on Age of Empires + Civilization patterns. The oil game should use Ages/Facilities/Crews like AoE and a prerequisite research graph like Civ.

What We Should Copy From Each Game

Age of Empires Pattern

  • Ages: macro progression gates.
  • Buildings: technologies live in the correct building, not one giant menu.
  • Workers: villagers gather resources and build structures.
  • Resources: economy determines what you can research/build.
  • Human pressure: opponents expand, block resources, and race your timing.

Civilization Pattern

  • Directed graph: each tech has prerequisite parent techs.
  • Research yield: science/knowledge accumulates over turns.
  • Unlocks: tech unlocks units, buildings, improvements, or actions.
  • Boosts: doing a real world task speeds matching research.
  • Separate civic track: law/policy is not the same as engineering tech.

How Research Feels In Game

  1. Pick one research node each turn.
  2. Node starts only if prerequisites and resources are available.
  3. During research, specialists are busy and unavailable for field actions.
  4. Completed tech unlocks visible map actions, new crews, or cheaper/faster operations.

Hierarchy Rules

  • Solid nodes are available or already unlocked.
  • Dim nodes are locked behind prerequisite tech.
  • Some nodes require multiple parents, e.g. Exploration Wells needs 2D Seismic and Rig Logistics.
  • Human players can specialize: survey-first, drilling-first, infrastructure-first, or business-first.
